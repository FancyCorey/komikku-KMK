# KMK Phase 3-4 Risk Register

Date: 2026-06-26 (last updated: 2026-06-28 — v0.7.20: Phase 7 closed — query-time blocked tag exclusion tests, local source decision documented)

Status: active risk register. R-001 and R-003 mitigated in KMK-Recs v0.7.11 (Phase 5: Source Evaluation Hardening). R-002 mitigated by honest failure state — not durable resume. Phase 3/4 code audit complete 2026-06-27 — DB gaps confirmed (DB-01, DB-02), security gaps confirmed (SEC-01 through SEC-10). New risks R-023 through R-028 added from audit.

Scope: full KMK fork delta from Komikku v1.13.6/current baseline.

Severity values:

- `critical`
- `high`
- `medium`
- `low`
- `unknown`
