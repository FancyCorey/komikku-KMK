# Feature explanations

These pages explain the current KMK features. They are organized by what a reader is trying to understand, not by the artifact used to explain it. Diagrams show the flow, while the surrounding text describes the visible behavior, important states, privacy boundary, and responsible source files.

- [For You](for-you.md): personalized rows, recent discovery, filtering, controlled variety, and exposure-aware ordering.
- [Recommendation settings](recommendation-settings.md): grouped controls, search, quick access, and how settings affect recommendations.
- [Source Evaluation](source-evaluation.md): source checks, continuation, reassessment, partial results, and failure explanations.
- [Sources to try and source priority](source-discovery-and-priority.md): discovery, ranking, installation handoff, and source order.

## Manga preferences and cross-source tools

- [OCR search](ocr-search.md): local indexing, page processing, search, navigation, and cleanup.
- [Backup and restore](backup-and-restore.md): backup selection, restore stages, conflict handling, and deliberate exclusions.
